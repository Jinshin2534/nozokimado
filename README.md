# のぞき窓

カメラで見ている人の目の位置を追いかけて、画面の向こうに3Dモデルが本当にあるように見せるWebページです。ソニーの空間再現ディスプレイ（ELF-MN1 など）の「目の位置に合わせて映像を作り直す」部分を、普通のMac・スマホの画面と内蔵カメラでやってみたものです。

- 画面を「窓」とみなし、目の位置から窓の四辺を通る視錐台（非対称な透視投影）を毎フレーム作り直します。頭を動かすと、窓の奥をのぞき込んだように見え方が変わります（運動視差）
- 目は MediaPipe Face Landmarker の虹彩ランドマークで検出します。大人の虹彩の直径がほぼ一定（約11.7mm）なことを使って、画面までの距離も出します
- **普通の画面には左右の目に別々の映像を届けるレンズが無いので、両目で見る立体視までは再現できません。** 片目をつぶると立体感が強くなります

## 使い方

- 開くとサンプルが表示されます。`.glb` / `.gltf`（1ファイルにまとまったもの）/ `.vrm` をドラッグ＆ドロップするか、「モデル・モーションを選ぶ」で読み込みます。アニメーション付きの glb はそのまま再生します
- **VRM は踊ります。** 外部データなしの組み込みダンス（32拍ループ、テンポ70〜180）で踊り、まばたきしながら見ている人と目を合わせます。`.vrma`（VRMアニメーション）を落とすと、そのモーションを繰り返し再生します（設定の「モーションを外す」で組み込みダンスに戻ります）
- キャラクターのモデルやモーションはこのリポジトリに含めていません。使う人が、利用条件を確認したうえで自分で用意してください
- **画面を長押し（Mac は S キー）** で設定が開きます。箱庭型／溶け込む型の切り替え、機種（画面の物理サイズとカメラ位置）、モデルの大きさ・向き、目の追跡のデバッグ表示
- 機種は画面解像度から自動で推測します。外れていたら機種を選ぶか、画面の横幅を cm で入力してください。サイズが合っていないと、奥行きが伸びたり縮んだりして見えます
- 読み込んだモデルはそのブラウザ（IndexedDB）にだけ保存し、どこにも送信しません

## 開発

```bash
pnpm install
pnpm dev     # http://localhost:6020
pnpm test    # 純粋ロジック(src/lib, 虹彩の計測)のテスト
pnpm build
```

## 構成

- `src/lib/geometry.js` 窓の視錐台、虹彩→距離、カメラ座標→画面座標、端末の向きとカメラ位置、ブラウザ窓のずれ
- `src/lib/filter.js` One Euro Filter（目の位置の揺れ止め）
- `src/lib/devices.js` 機種プリセット（物理サイズは対角インチと解像度から計算）と自動推測
- `src/lib/fit.js` モデルを空間に収める拡大率
- `src/lib/dance.js` 組み込みダンス（拍 → VRM 正規化ボーンの回転）
- `src/tracker.js` 目の検出、`src/scene.js` 箱庭/溶け込む空間とモデル読み込み、`src/main.js` 配線
- `window.__app.setEye({x, y, z})`（m、画面中心基準）で、カメラなしで見え方を検証できます
